## 2. 目标与范围

### 2.1 重构后业务流

```text
教师建课+上传录音 → 异步转写 → AI 评析（摘要/亮点/待改进/风险/证据/置信度）
  → 教师工作台查看反馈 → 加入清单/写反思 → 教师自评完成
  → 每5条抽1条 → 督导写评语 → 督导确认关闭改进项
```

### 2.2 本轮做 / 不做

- 做：教师建课、录音覆盖/删除/回听（本人）、转写、AI 任务、抽样分派、督导纯评语、反思页、简化清单、站内信、演示模式、报告导出打印视图、导航补齐、课表下拉。
- 不做：浏览器录音业务功能（仅原型）、督导打分、综合分双源融合、N6/N8/N10/N11、音频归档清理、实时转写/视频分析/教务对接/移动端 App。

## 4. 接口契约（事实源同步到 `backend_AGENTS.md` §8，前缀 `/api/v1`）

### 4.1 授课与录音

| 方法路径 | 权限 | 说明 |
|----------|------|------|
| `POST /sessions` | teacher（本人课程）/ supervisor | 教师建课：`courseId/classId/sessionDate/period/topic`，`classId` 必填；督导建课保留。日期不得晚于今天。 |
| `DELETE /sessions/:id` | 创建者本人 / supervisor | 级联删录音文件+转写+AI 行+清单关联（service 事务）。**新增** |
| `POST /sessions/:id/recording` | teacher（本人）/ supervisor | **覆盖语义**：有旧文件则替换并重置转写为 pending。白名单 mp3/wav/m4a 不变。 |
| `DELETE /sessions/:id/recording` | 上传者本人 / supervisor | 删文件+重置转写。**新增** |
| `GET /sessions/:id/transcript` | 登录（数据裁剪） | 不变；教师侧同样返回脱敏文本+segments。 |
| `GET /recordings/:id/stream` | supervisor 全量 + **上传者本人** | B3 变更：service 层放行 `uploaded_by == userID`。 |

### 4.2 AI 任务（D3，全部新增）

| 方法路径 | 说明 |
|----------|------|
| `POST /sessions/:id/ai-observation/analyze` | 入队 AI 评析（幂等，有未完成任务直接返回 taskId，不重复建）。 |
| `GET /sessions/:id/ai-observation` | AI 观察详情：摘要/亮点/待改进/风险（督导可见）/证据/置信度/模型版本/时间。教师侧风险标签脱敏（D8）。 |
| `GET /ai-tasks/:id` | 任务状态查询（pending/running/done/failed+error）。 |
| `POST /ai-tasks/:id/retry` | supervisor 可重试。 |

转写完成自动入队 AI（service 内调用，不经 HTTP）；AI 失败只记任务，不阻断页面。

### 4.3 督导评语（B2/B8，纯文本）

| 方法路径 | 说明 |
|----------|------|
| `GET /supervision/ai-tasks` | 督导抽样任务队列：待人工复评（被抽中）+ 可浏览全部历史。分页+学期切片。 |
| `PUT /sessions/:id/supervisor-observation` | 提交/覆盖督导观察：亮点/主要问题/学生参与/改进建议/复查要求/审核意见。**无五维分**，缺全空允许（至少填一项）。 |
| 抽样规则 | 同一教师 AI 终评计数每满 5 触发 1 次；候选=最近 5 条；有风险标签取标签项，否则取 AI 综合分最低。计数器存 `teacher_ai_reports` 或独立计数表，实现自选但 PR 必说明。 |

### 4.4 清单/反思/通知/课表/报告

| 方法路径 | 说明 |
|----------|------|
| `GET/POST /improvement-items`、`PUT /improvement-items/:id`、`PUT /improvement-items/:id/complete`（教师自评）、`PUT /improvement-items/:id/close`（督导确认） | N4 简化版：标题+来源+完成说明+三态（open/done_self/closed）。 |
| `GET/POST/PUT /teaching-reflections` | N5：收藏某条评语（source_eval_id）+反思/计划/下节行动，教师私有，督导关闭清单时可读。 |
| `GET /notifications`、`PUT /notifications/:id/read`、`PUT /notifications/read-all`（注意注册顺序） | B12：只推 supervisor_comment / ai_issue；列表分页。 |
| `GET /timetable/mine` | B11：本人课表下拉数据源。 |
| `GET /teachers/:id/report?semester=` | N9：报告数据接口（综合分+五维+最近3评语+清单），前端另做打印视图。 |
| `POST /demo/seed` | B6/N7：载入示例数据（仅开发演示环境可用，生产禁用）。 |

### 4.5 废弃接口

`PUT /sessions/:id/supervisor-evaluation`（五维打分）、`/sessions/:id/draft`、`/drafts*`：停止前端调用，后端暂留（返回 501/空），下轮删除。

## 6. 评价口径（B8+B10，破坏性，以本节为准）

- 计分**只按 AI**：`composite = AI 单侧总分`；教师级/课程级 = 各场次 AI 综合分均值。`supervisorWeight α` 废弃。
- 主视图维度：互动/参与/组织/提问讨论优先展示；目标/内容维度保留但标注“AI 部分可观察、低置信度可为 NULL”。
- 督导意见独立“督导观察”模块：督导名+日期+结论+复查要求，与 AI 分数不混合。
- 伦理：全端显著标注“仅用于教学支持，不作为考核依据”；高风险标签永不进教师端（D8）。
- 旧种子 `supervisor` 行与 `verify.sh` 督导分断言：重构 PR 中同步重算/删除，不得留红。
