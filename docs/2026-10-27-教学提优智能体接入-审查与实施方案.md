## 1. 已锁定决策（后续实现不得再改，除非用户重新裁定）

| # | 决策项 | 结论 |
|---|---|---|
| D1 | 场次状态 | `teaching_sessions.status='evaluated'` 含义为 **AI 已评析**（S1 完成），由 AI 任务写入；督导是否已评由 DTO 字段 `supervisorEvaluated`（bool）从 `evaluations` 的 `evaluator_type='supervisor'` 行推导，**不新增数据库列** |
| D2 | 督导覆盖率 | **停用**：`GET /supervision/coverage` 保留 deprecated；不再作为业务指标、页面展示与验收项 |
| D3 | 单次课报告 | 复用 `evaluations` 的 agent 行（五维分 + 四段评语 + `evidence` + 置信度 + 模型/提示词版本），**不新建 `session_ai_reports`** |
| D4 | 教师综合报告 | 固定 `(teacher_id, semester, course_id=0)`，覆盖该教师本学期**全部课程**；每次 S1 `done` 都入队更新，**10 分钟去抖 + `source_session_ids` 快照比对**；A1→A2 覆盖同一行，A2 基于 a1+a2 |
| D5 | 评分趋势 | 按场次记录直接出点（AI 单源、`formula_version` 过滤、无评价点 `value=null`）；**不建表、不做时间衰减** |
| D6 | 知识库 | `kb-rubric` 只放**项目五维锚点**（与 `pkg/scoring` 的 5 维 1–5 完全一致）；TQF / ICAP / Formative Feedback 等英文框架放 `kb-strategy`；知识库迁移为 **V16**；向量模型固定 `qwen3.7-text-embedding-flash`、1024 维、batch 20，选定后不得更换 |
| D7 | 触发点 | **上传 → ASR 转写 `done` → S1**；文本模型不能直接读音频，不存在“上传即评估” |
| D8 | 对话 | 无状态 SSE；前端携带 ≤6 轮 `history`，服务端不落库 |
| D9 | 提优建议接口 | `GET /courses/:id/agent-suggestions?semester=` **v1 返回数组**，取消 RAG 原 `page/pageSize`（与前端 `fetchAgentSuggestionsApi` 签名一致） |
| D10 | 督导抽样 | 保持 B2「每 5 条 AI 终评抽 1 条」；`reviewed` 仍由督导评价行判断，不新增分配表 |

## 4. 目标与非目标

**目标（本轮）**

1. 提优页（教师端）三个区块接真实数据：AI 提优建议、分数趋势、AI 对话。
2. 教师级 AI 综合报告（S2）可生成、可读取、可重生成，并在「我的质量档案」展示；A1→A2 覆盖更新。
3. AI 评析链路与督导流程解耦：AI 只写 `status='evaluated'`（AI 已评），督导状态用 `supervisorEvaluated`。
4. 知识库可离线构建，S1/S2/S3 可引用 `kb-rubric`（分阶段，允许后置）。
5. 前端删除 `src/mocks/teacherImprove.ts`，全站无 AI mock。
6. 文档与契约同步，消除“代码已实现、文档说没有”的状态。

**非目标**

- 说话人分离、声学特征分析；向量数据库 / ES；对话历史落库；学生端/家长端/移动端；督导五维评分复活；教师级报告历史版本表。

| 方法 路径 | 权限 | 返回 |
|---|---|---|
