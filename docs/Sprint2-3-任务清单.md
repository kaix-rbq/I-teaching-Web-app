## 一、后端基础（阶段①）

1. 引入 `golang-migrate`，建 `teaching_sessions`（授课记录）与 `evaluations`（评价）两张表
2. 新增 `TeachingSession`、`Evaluation` 模型，字段与 DDL 一一对应
3. 新增评分计算模块：维度权重、单次总分、三级聚合（**综合均值口径**），写成纯函数并配表驱动单测
4. 授课记录的增查与归属校验（督导建课，越权返回 40302）
5. 督导评分提交：**五维必填**、幂等覆盖，同时写入口径版本号
6. 教师级 / 课程级评分聚合，做成**主任端与教师端共用的唯一出口**
7. 注册全部新接口与角色守卫，确保 Sprint 1 接口无回归
8. 扩充种子数据，并在验收脚本中补充断言

## 二、教研室主任页面（阶段①）

1. 工作台不再显示课程表格与近期开课列表，改为「课程管理」「教师管理」两个入口卡，保留统计卡
2. 新增「教师管理」页面并同步侧边栏，以列表展示本室教师的综合评分、各维度分与评价次数
3. 点击教师条目跳转到新增的教师评分数据面板：综合分 + 分维度分 + 按课程明细 + 历次评价时间线
4. 列表默认按姓名排序，评价次数不足 3 次的标注"样本不足"，页面标注"仅用于教学支持，不作为考核依据"

## 三、教学督导页面（阶段①）

1. 「督导总览」与工作台合并，重复的统计卡与覆盖率卡只保留一处；原页面改造为「听评课管理」，保留完整分页与筛选
2. 工作台「听评课安排」中点击课程，跳转到课程详情页
3. 课程详情页在基础信息之外，新增该课程的历史授课记录列表
4. 点击某次授课记录，跳转到新增的当堂课质量评估页
5. 评估页支持按 5 个维度打分并填写结构化评语（亮点 / 待改进 / 建议），评分锚点以 tooltip 呈现
6. 评估页预留智能体评价展示位，阶段②接入真实智能体

## 四、教学督导页面 · 录音与智能体（阶段②）

1. 课堂录音上传与流式播放
2. 异步语音转写任务，含状态轮询与失败重试
3. 转写文本中的学生姓名脱敏
4. 接入智能体评分，写入评价表的智能体行，无法观测的维度留空
5. 评估页新增「智能体参考」对比面板，标注"AI 参考"与低置信度维度
6. 综合分生效：督导评分与智能体评分按场次对齐后加权融合
7. 音频播放写入审计日志

## 五、教师页面（阶段①）

1. 新增「教学提优」页面，由「我的课程」点击课程条目跳转
2. 保留课程基本信息（学分 / 学时 / 学期 / 班级 / 学生人次）与资源上传接口
3. 展示本课程在各维度下的督导评分与综合评分
4. 展示本人综合分与各维度分，并标注样本量

## 六、教师页面 · 提优（阶段③）

1. 查看督导评语（仅本人可见，按时间倒序，标注对应课次）
2. 查看智能体针对课堂记录给出的提优建议
3. 查看各维度分数的历史趋势折线
4. 与智能体就课堂改进对话（流式输出）
