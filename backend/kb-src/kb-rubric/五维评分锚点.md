# 五维评分锚点（项目版 v1）

> 适用范围：本项目 `formula_version = v1` 的五维课堂评价，供 S1 单次课 AI 评析与人工复核共用。
> 维度固定为 `objective`、`content`、`interaction`、`organization`、`frontier` 五项，分值固定为 **1–5 整数**；
> `objective` 30%、`content` 30%、`interaction` 20%、`organization` 20%、`frontier` 0%（观测项）。
> 本文件是项目自有标准，**不得用 TQF 等 7 维 0–4 框架替代**；外部框架只作 `kb-strategy` 参考。

## 评分总则

### 通用分值含义

| 分值 | 等级 | 通用含义 |
|---|---|---|
| 5 | 优秀 | 可作为示范课；证据充分且稳定，不是偶发亮点 |
| 4 | 良好 | 达到骨干教师水平；整体成立，仅有可优化细节 |
| 3 | 合格 | 达到基本教学要求；无硬伤，但缺少突出表现 |
| 2 | 待改进 | 存在明显短板，已影响该维度的教学效果 |
| 1 | 不合格 | 该维度基本缺失或出现需要立即干预的问题 |

### 五条评分纪律

1. **只评可观察证据**：分数必须由课堂转写中的具体话语支撑；不能根据教师职称、课程难度、学生基础、历史评分或督导意见推断。
2. **一维一评**：五个维度独立判断，禁止晕轮效应（halo effect，某维表现好就整体加分）或“补偿心理”（某维差就用另一维拉平）。
3. **无法观察写 `null`**：没有足够证据时写 `null` 并计入 `notObservable`，禁止为了凑满五维强行给 3 分。
4. **无证据不给分**：每个非 `null` 维度至少附 1 条能在脱敏转写中逐字定位的引用；引用定位失败即视为无证据。
5. **证据强度决定置信度**：证据充分且具体时置信度高；证据不足时降低置信度，但**不得用低置信度掩盖无证据给分**。维度置信度低于 0.4 时按 `null` 处理；`interaction` 缺学生话语时直接 `null`，不是“降置信度后照常给分”。

### 两条硬性禁令

- `organization` **不得以“学生安静 / 音量低 / 没有吵闹”作为正向证据**。安静可能是满堂灌或学生走神，不等于组织好。
- `frontier` **不得因基础课性质而扣分**。操作系统、计算机组成原理等基础课没有前沿内容属正常；无前沿内容应写 `null`，不是 1 分或 2 分。

## objective：教学目标与内容准确性（权重 30%）

### 定义与观测边界

看三件事：**目标是否明确、内容是否准确、重难点是否突出**。目标要能指导本节课的教学，而不是“了解……掌握……”式的空话；内容准确性包括概念、原理、公式、代码、事实与逻辑；重难点要有相应的讲解投入和取舍。

AI 没有教材、教学大纲和学生先修数据，**不能仅凭“没提到教材”判定目标缺失或内容错误**。可从转写中观察：

- 教师是否明确说出本节课目标、任务或要解决的问题；
- 是否出现可识别的知识性错误、前后矛盾或错误类比；
- 是否把主要时间放在关键概念/难点上，而不是平均用力或跑题。

若转写只包含课堂管理、点名、设备调试等非教学话语，无法判断目标与准确性时，写 `null`。

### 目标维度锚点（1–5 分行为描述）

| 分值 | 行为锚点 | 典型证据 |
|---|---|---|
| 5 | 目标明确、可检验；内容准确无错误；重难点突出且有取舍；前后逻辑自洽，能回到目标收束 | 教师开篇/结尾明确交代目标；对难点有多角度解释；无知识性错误；总结与目标呼应 |
| 4 | 目标清晰；内容准确；重难点较突出；仅个别细节或表述可优化 | 有目标陈述；关键概念解释正确；难点有专门讲解；偶有表述不严谨但不影响理解 |
| 3 | 目标基本清晰；无实质性知识错误；按部就班完成内容，重难点不够突出 | 有教学任务但目标较笼统；内容正确；难点一笔带过或未区分主次 |
| 2 | 目标不够清晰，或存在个别知识性瑕疵，或重难点明显不清 | 目标仅“大家看一下”；有概念混淆/错误类比；难点未展开；学生可能被误导 |
| 1 | 目标缺失，或存在影响理解的知识性错误，或内容明显偏离课程主题 | 全程无目标；核心概念讲错；内容与课程无关；错误未纠正 |

### 常见误判

- **内容多 ≠ 目标明确**：讲了很多知识点但没说明“为什么学、学到什么程度”，目标项不能给 4/5。
- **口才好 ≠ 内容准确**：表达流畅但概念错误，必须按错误严重程度降至 1–2 分。
- **没有教材 ≠ 无法评价**：转写中有明确目标与知识陈述时仍可评；只有无法判断时才写 `null`。
- **课程难 ≠ 目标清楚**：难度不是加分项；把难题讲清楚才是。

## content：内容质量与深度（权重 30%）

### 定义与观测边界

看内容是否**充实、有结构、有深度、理论联系实际**：是否讲清“是什么、为什么、怎么用”；是否有恰当的案例、例题、实验或工程场景；是否有取舍，而不是照本宣科或堆砌术语。

AI 可依据转写中的解释链、例子、类比、提问与练习判断深度；**不能仅凭“没讲某章节”判定内容偏薄**，因为不知道教学进度。若转写只有通知、点名、纪律管理，写 `null`。

不同课型用不同证据，不要求所有课都“理论联系实际”：

- 理论课：概念解释、推导、反例、适用条件；
- 习题课：题目选择、思路拆解、错误分析、方法迁移；
- 实验/实践课：任务设计、操作要点、现象解释、安全与规范；
- 复习课：知识网络、易错点、综合应用，而不是简单重复。

### 内容维度锚点（1–5 分行为描述）

| 分值 | 行为锚点 | 典型证据 |
|---|---|---|
| 5 | 内容充实且有清晰结构；讲清原理与适用条件；理论联系实际自然；案例/例题贴切；有取舍、有深度 | 用真实工程/科研案例解释抽象概念；对“为什么”有追问；能指出常见误区；内容服务于目标 |
| 4 | 内容较充实；理论与实际结合较好；案例/例题基本贴切；深度较好 | 有解释链和例子；能联系应用场景；个别例子略泛但整体成立 |
| 3 | 内容完整但以照本宣科/平铺直叙为主；例子较少或较表面；深度一般 | 按教材顺序讲完；有定义和结论但缺少“为什么”；案例仅一笔带过 |
| 2 | 内容偏薄；案例或解释不足；深度不够；存在明显“水”内容 | 大量时间读 PPT/念定义；缺少例子；重复已知内容；未解释关键机制 |
| 1 | 内容空洞或明显偏离主题；基本没有有效教学内容 | 与课程无关的闲聊占主导；内容严重不足；学生无法获得有效知识 |

### 常见误判

- **术语多 ≠ 有深度**：堆砌名词但未解释机制，不能给 4/5。
- **前沿 = 深度**：前沿内容属 `frontier`，不能替代 `content` 的讲解质量。
- **案例多 ≠ 联系实际**：案例与知识点无关或只做开场噱头，不能高分。
- **习题课/实验课 ≠ 内容薄**：任务设计、错误分析、操作指导同样是内容质量。

## interaction：学生互动与参与（权重 20%）

### 定义与观测边界

看教师是否**发起并维持有效的师生/生生互动**，学生是否有真实的表达、讨论与回应。未启用说话人分离，AI 只能依据**语言线索**判断，不能依据音量、静音占比或声学特征。

| 线索 | 高分表现 | 低分表现 |
|---|---|---|
| 教师设问 | 开放性、追问式问题为主 | “是不是”“对不对”等封闭确认题为主 |
| 主动发起 | 点名提问、邀请表达、组织小组并巡视参与 | 全程单向讲授，无主动发起 |
| 问题后处理 | 给出思考时间、倾听后追问一层 | 自问自答、立即给答案 |
| 学生话语痕迹 | 转写中有学生回答、提问、讨论内容 | 只有教师独白 |
| 反馈质量 | 针对回答内容做具体评价、纠正或追问 | 仅“很好”“对”式笼统回应 |

**AI 的 `null` 规则**：转写若只有教师话语、没有任何可识别的学生话语，**不能仅凭“没看到学生说话”直接判 1 分**——可能是 ASR 未区分说话人或学生声音未被采集。按项目 RAG 方案 §6.5 口径，**缺学生话语证据时写 `null` 并计入 `notObservable`**，不要用教师独白推断“互动差”：

1. 教师有提问但转写中没有任何学生回应 → `interaction = null`，`notObservable` 加入 `interaction`；可在评语中提示“转写未捕获学生话语，建议督导现场复核”。
2. 教师明确自问自答，且整段无任何学生话语 → 同样写 `null`，不要给 1–2 分；只有在存在学生话语、可确认互动形态时，才按 1–5 评分。
3. 转写明显缺失整段互动环节（如只有开场/总结）→ `null`，计入 `notObservable`。
4. 有人工督导在场观察时，以人工观察为准；人工可依据现场情况给 1 分（全程单向讲授），AI 分数只作参考。

### 互动维度锚点（1–5 分行为描述）

| 分值 | 行为锚点 | 典型证据 |
|---|---|---|
| 5 | 开放问题与追问充分；有等待时间；学生真实表达/讨论；反馈具体且推动思考；参与面广 | 教师问“为什么/如果改变条件会怎样”；点名后等待；学生提出不同解法；教师追问“你的依据是什么” |
| 4 | 提问与讨论较多；多数学生有参与；偶有封闭问题但不主导 | 多次邀请学生回答；有小组讨论；教师对回答做具体回应 |
| 3 | 偶有提问，但以自问自答或封闭确认题为主；学生回应较少 | “对不对？”“是吧？”后教师自己接话；个别学生简短回答 |
| 2 | 互动很少；学生仅简单应答；教师主导明显 | 长时间讲授后问“听懂了吗”；学生只回答“懂了/对” |
| 1 | 全程单向讲授，无任何互动或学生话语（人工可判；AI 无学生话语证据时应写 `null`，不据此判 1） | 整段只有教师独白；无提问、无点名、无讨论 |

### 常见误判

- **学生安静 ≠ 互动差**：安静可能是思考或记录；但也不能把安静当作互动好。
- **齐声回答 ≠ 深度参与**：全班齐答“对/是”属于低质量互动，不能给 4/5。
- **提问多 ≠ 互动好**：连续封闭题、自问自答仍是低分；但若整段没有学生话语，按 `null` 处理，不据此判低分。
- **点名次数 ≠ 参与面广**：AI 只能看到被点名者的话语；没有多个学生表达的证据时，不给 5 分，置信度也应降低。
- **互动多 ≠ 内容好**：互动只评互动，不能补偿 `content` 的不足。

## organization：课堂组织与节奏（权重 20%）

### 定义与观测边界

看**教学环节是否清晰、时间分配是否合理、节奏是否得当、课堂秩序与突发情况处理是否有效**。不以“课堂安静”作为组织好的证据；也不以“互动多”作为组织差的证据。

可从转写观察：环节过渡语、任务指令、时间提示（“最后五分钟”）、小结与收尾、点名/分组/设备切换的组织方式、拖堂或提前结束的痕迹。转写时间戳可用于判断各环节占比；没有时间戳或只有片段时，写 `null` 或降低置信度。

### 组织维度锚点（1–5 分行为描述）

| 分值 | 行为锚点 | 典型证据 |
|---|---|---|
| 5 | 环节清晰且有过渡；时间分配合理；重点环节留足时间；按时开始/结束；突发处理得当 | 开篇交代流程；环节间有明确过渡；总结不仓促；无拖堂；设备/纪律问题快速处理 |
| 4 | 环节清晰；时间分配基本合理；仅有轻微失衡 | 流程完整；某环节略长/略短但不影响整体；收尾基本完整 |
| 3 | 环节完整，但时间分配略显失衡或过渡生硬 | 总结仓促；某环节占用过多；环节切换缺少说明 |
| 2 | 环节不够完整，或时间分配明显失衡，或出现明显拖堂/提前结束 | 重点内容没讲完；长时间跑题；下课铃后仍在讲；提前结束 |
| 1 | 结构混乱，或严重拖堂/提前下课，基本环节无法完成 | 无流程；频繁跳转；严重超时；学生不知道要做什么 |

### 常见误判

- **安静 ≠ 组织好**：学生安静可能因为满堂灌、畏缩或走神；不得作为正向证据。
- **内容多 ≠ 节奏好**：塞满内容导致重点环节被压缩，应降分。
- **互动多 ≠ 组织差**：小组讨论、动手实践本身需要时间，不能因“看起来乱”扣分；看是否有指令、分工与收束。
- **拖堂 ≠ 敬业**：占用课间属于时间分配问题，按程度降分。

## frontier：前沿与交叉学科（权重 0%，观测项）

### 定义与观测边界

看是否**自然融入学科前沿、产业进展或交叉学科应用**，并与本节课主线结合。它是观测项，**不计入加权总分**；只作为亮点或改进建议，不改变综合分。

AI 只在转写中出现可识别的具体前沿/交叉内容时给分；只出现“人工智能”“大数据”等泛化热词，不算前沿。**没有前沿内容时写 `null`，不写 1 分或 2 分**；基础课、习题课、实验课不因无前沿内容被扣分。

### 前沿维度锚点（1–5 分行为描述）

| 分值 | 行为锚点 | 典型证据 |
|---|---|---|
| 5 | 前沿/交叉内容与主线自然结合，能解释“为什么重要”，并回到本节课知识点 | 用近两年论文/产业案例解释原理；指出该方向未解决问题；与课程概念形成清晰映射 |
| 4 | 较好结合前沿/交叉应用，结合基本自然 | 举出具体技术/产品/研究案例；与知识点有明确关联 |
| 3 | 提及前沿但较生硬，或只作开场/结束的点缀 | 提到某个热点但未展开；与主线关联弱 |
| 2 | 前沿内容很少且结合生硬，或存在误导性类比 | 硬塞热点；案例与知识点脱节；夸大/错误解读 |
| 1 | 无前沿内容（**不单独作为扣分依据**；AI 应优先写 `null`） | 整节课未涉及前沿/交叉内容 |

### 常见误判

- **提到“AI/大数据” ≠ 前沿**：没有具体进展、案例或与知识点的连接，不能给 4/5。
- **基础课无前沿 ≠ 低分**：这是课程性质，写 `null` 并在建议中说明即可。
- **前沿内容多 ≠ 内容有深度**：前沿不能替代 `content`；两者分开评。
- **交叉学科 ≠ 拼盘**：与主线无关的“跨学科”堆砌不给高分。

## 评分操作顺序（S1 与人工复核共用）

1. **通读转写**：标记课堂目标、主要教学环节、关键概念/难点、师生话语、时间戳。
2. **逐维取证**：每个维度先找 1–2 条原文，再定分；找不到证据就写 `null`。
3. **独立定分**：先按维度锚点定 1–5，再检查是否受其他维度影响。
4. **硬约束复核**：`organization` 是否误用“安静”作正向证据；`frontier` 是否因基础课扣分。
5. **写引用**：`quote` 必须逐字来自脱敏转写，附 `start/end` 秒；不要改写、概括或拼接。
6. **写置信度**：证据充分且具体 → 高；只有间接线索/片段缺失 → 中；无法判断 → `null` 并列入 `notObservable`。

## 常见争议裁定

| 情形 | 裁定 |
|---|---|
| 课堂很安静、学生没有吵闹 | `organization` 不得因此加分；`interaction` 也不能因此加分 |
| 基础课没有前沿内容 | `frontier = null`，不扣分；不得写 1 分作为惩罚 |
| 教师全程讲授但内容准确、结构清晰 | `content`/`objective`/`organization` 可正常评价；`interaction` 按互动线索评，不能因“没互动”否定其他维度 |
| 学生基础差、回应少 | 不因学生基础扣教师分；只评教师是否发起、等待、追问与反馈 |
| 复习课/习题课没有理论深度 | 按任务设计、思路拆解、错误分析评 `content`，不套用理论课标准 |
| 实验课/实践课 | 按任务指令、操作要点、现象解释、组织与安全评；不要求前沿 |
| 双语/口音/语速 | 不作为评分维度；只要不影响理解，不扣分 |
| 课堂出现设备故障 | 看教师处理是否得当；处理得当不扣 `organization`，处理失当才扣 |
| 督导评分与 AI 评分不一致 | 各自独立；AI 不因督导分数调整，人工复核也不因 AI 分数改分 |

## 引用与置信度示例（格式约束）

- 合格引用：`{"start": 123.4, "end": 145.0, "quote": "大家先自己估一下，再和旁边同学对一下，看差多少"}`——能在转写中逐字找到，且能支撑 `interaction` 的“组织同伴讨论”。
- 不合格引用：概括句“教师组织了小组讨论”、转写中不存在的句子、把两句不相邻的话拼接、只写时间不写原文。
- 置信度建议：直接证据 + 多个线索 → 0.7–0.9；单一间接线索 → 0.4–0.6；证据不足但尚可判断 → 0.4 左右；低于 0.4 按 `null`；只有教师独白时不要给 `interaction` 计分；无法观察 → 0 并写 `null`。

## 维护约定

- 本文件为 **v1**，与 `pkg/scoring` 的 `formula_version = v1` 对齐；维度、权重、1–5 标度变更时必须同步 `pkg/scoring`、前端 `EVALUATION_DIMENSIONS` / `DIMENSION_ANCHORS` 与本文件，并递增版本。
- `kb-rubric` 只放项目五维锚点与输出模板；TQF、ICAP、Formative Feedback 等外部框架放 `kb-strategy`，不得混入本集合。
- 修改本文件后需重新摄取 `kb-rubric`（`go run ./cmd/kb ingest ...`），历史评价的 `formula_version` 不随文档变更而改。
